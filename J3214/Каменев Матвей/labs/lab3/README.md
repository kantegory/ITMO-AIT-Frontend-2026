# annotaylor
Платформа для автоматизированной подготовки и аннотации данных для ML  

Структура:
- Страница с заказами на аннотации датасетов. Возможность поиска по названию и фильтрация по типам аннотации.
- Отдельные страницы каждой аннотации. Классификация изображения/текста, баундбоксы для детекции объектов на изображении и NER.
- Профиль со статистикой заказов и аннотаций.

Модальные окна входа и регистрации.

Добавлено внешнее API open.er-api.com для конвертации валют в ценах аннотаций, добавлено моковое API регистрации (если я правильно понял задание, надо и то, и то)

Добавлены aria-лейблы, проверял корректность в Firefox Dev tools.

Добавлены светлая и темные темы с ориентиром на пользовательские настройки.

## ЛР3: миграция на Vue.js

Приложение переписано на Vue 3 (Vite, vue-router, Pinia, axios). Все данные, которые раньше были захардкожены в HTML, лежат в `db.json` и загружаются через json-server.

- `src/router` — маршруты `/`, `/profile`, `/projects/:id`, `/orders/:id/annotate`; гвард отправляет неавторизованного пользователя на главную с окном входа и возвращает на запрошенную страницу после входа.
- `src/api` — axios-инстанс и классы API по ресурсам (заказы, аннотации, профиль, проекты, дата поинты, результаты разметки, курсы валют).
- `src/stores` Pinia-сторы: авторизация, заказы, принятые заказы, профиль, проекты, текущая задача разметки.
- `src/composables` переиспользуемая логика: `useCurrency` (курсы и форматирование цен), `useRequest` (состояние загрузки/ошибки), `useModal` (модальные окна Bootstrap), `useAuthForm` (общая логика форм входа и регистрации), `useEventListener`, `useTheme`, `useDocumentTitle`.
- `src/layouts`, `src/components`, `src/views` макет, компоненты и страницы.

Результат разметки теперь сохраняется: «Подтвердить» отправляет его на сервер и переходит к следующему дата поинту. Размечать можно только принятый заказ.

Запуск бэка: `npm install && npm run server`; запуск фронта: `npm run dev` (http://localhost:8080). Тестовый пользователь: admin@example.com / admin.
