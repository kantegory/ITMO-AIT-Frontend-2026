# Домашние работы 2-4

Папка содержит доработку ранее выбранной темы: платформы онлайн-курсов **Omagad**.

## ДЗ 2: доступность в HTML

Что сделано:

- указан язык страницы `lang="ru"`;
- добавлены `meta viewport` и `meta description`;
- использованы семантические теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- добавлена skip-ссылка для перехода к основному содержимому;
- навигация получила `aria-label`;
- секции связаны с заголовками через `aria-labelledby`;
- декоративные SVG скрыты через `aria-hidden="true"`;
- интерактивные элементы имеют доступные подписи;
- поля формы связаны с `label`, а группа радиокнопок оформлена через `fieldset` и `legend`;
- количество найденных курсов обновляется в области с `aria-live="polite"`;
- добавлены видимые стили `:focus-visible` для клавиатурной навигации.

## ДЗ 3: CSS-переменные и темизация

Что сделано:

- цвета, радиусы, тени и размеры вынесены в CSS-переменные в `:root`;
- добавлена тёмная тема через `[data-theme="dark"]`;
- учтены системные настройки пользователя через `prefers-color-scheme`;
- реализован переключатель темы на JavaScript;
- выбранная тема сохраняется в `localStorage`.

## ДЗ 4: SVG-спрайт

Что сделано:

- иконки собраны в общий SVG-спрайт;
- рабочий спрайт подключён inline в начале `index.html`, чтобы страница корректно открывалась напрямую без dev-сервера;
- копия спрайта также лежит в `assets/sprite.svg`;
- на странице используются символы через `<use href="#...">`;
- добавлены иконки логотипа, поиска, пользователя, сертификата, солнца и луны;
- SVG-иконки не дублируются в HTML как отдельные inline-рисунки.

## Файлы

- `index.html` - доступная HTML-страница;
- `styles.css` - стили, CSS-переменные и адаптивность;
- `theme.js` - переключение темы и фильтрация курсов;
- `assets/sprite.svg` - копия общего SVG-спрайта отдельным файлом;
- `preview.png` - скриншот результата.

## Как проверить

Открыть `index.html` в браузере. Проверить:

- переход по клавише Tab и видимый фокус;
- работу skip-ссылки;
- переключение светлой и тёмной темы;
- сохранение темы после перезагрузки страницы;
- фильтрацию курсов по названию и уровню;
- использование иконок из SVG-спрайта.
