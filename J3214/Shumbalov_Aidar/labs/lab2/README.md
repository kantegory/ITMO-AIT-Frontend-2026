# Лабораторная работа 2

Тема: взаимодействие с внешним API на примере платформы онлайн-курсов **Omagad**.

## Что реализовано

- Mock API на `json-server` и `json-server-auth`.
- Авторизация и регистрация через `/login` и `/register`.
- Хранение токена и пользователя в `localStorage`.
- Получение каталога курсов через `fetch('/courses')`.
- Получение записей пользователя через защищенный ресурс `/enrollments`.
- Фильтрация курсов по названию, предмету, уровню и цене.
- Личный кабинет пользователя с прогрессом, купленными курсами и сертификатами.
- Страница курса с материалами, преподавателем, рейтингом и количеством лекций.

## Данные для входа

```txt
email: student@omagad.ru
password: password123
```

## Команды

```bash
npm install
npm run api
npm run web
npm run build
```

Или в двух процессах одной командой:

```bash
npm run dev
```

После запуска:

- фронтенд: `http://127.0.0.1:5174/`;
- API: `http://127.0.0.1:3001/`.

## Файлы

- `index.html` - интерфейс лабораторной;
- `app.js` - работа с `fetch`, авторизацией и рендерингом;
- `styles.css` - адаптивные стили;
- `db.json` - данные mock API;
- `routes.json` - права доступа для `json-server-auth`;
- `package.json` - npm-скрипты и зависимости.
