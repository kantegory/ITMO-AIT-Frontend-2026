# Лабораторная работа 1

Тема: платформа онлайн-курсов **Omagad**.

## Что реализовано

- Вёрстка сайта средствами HTML, CSS и Bootstrap.
- Обязательные страницы: вход, регистрация, личный кабинет пользователя, поиск курсов с фильтрацией.
- Дополнительные страницы варианта: страница курса и кабинет преподавателя.
- Фильтрация курсов по названию, предмету, уровню и цене.
- Семантическая разметка, подписи форм, skip-ссылка и `aria-live` для результата поиска.

## Как открыть

Открыть `index.html` в браузере. Основные страницы связаны навигацией:

- `index.html` - поиск и фильтрация курсов;
- `login.html` - вход;
- `register.html` - регистрация;
- `profile.html` - личный кабинет;
- `course.html` - страница курса;
- `teacher.html` - кабинет преподавателя.
