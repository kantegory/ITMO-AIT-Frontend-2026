## Задание

Свёрстать сайт по варианту №4 «Сервис для управления личными финансами и бюджетом».
Обязательные страницы:

- Вход (`login.html`)
- Регистрация (`register.html`)
- Личный кабинет пользователя — счета, транзакции, бюджеты (`dashboard.html`)
- Поиск и фильтрация транзакций по категории, сумме и дате (`search.html`)
- Страница отчёта — графики расходов, категории, прогнозы (`report.html`)

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3 + Bootstrap 5.3 (CDN)
- JavaScript (модальные окна, валидация форм)
