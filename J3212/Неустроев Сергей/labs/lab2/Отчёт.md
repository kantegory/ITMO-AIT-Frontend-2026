## Цель работы

Привязать свёрстанный в ЛР1 сайт к внешнему API средствами `fetch`/`axios`/`xhr`.
Реализовать моковое API средствами JSON-сервера и подключить к нему авторизацию.

## Задание

- Поднять мок-API на `json-server`
- Реализовать авторизацию (регистрация/вход, хранение токена)
- Подгружать и отправлять данные приложения (счета, транзакции, бюджеты) через API
- Реализовать поиск/фильтрацию транзакций через query-параметры API

## Используемые технологии

- json-server + json-server-auth (мок-API и JWT-авторизация)
- Fetch API (`js/api.js`), модульный JS (`type="module"`)
- localStorage для хранения токена
