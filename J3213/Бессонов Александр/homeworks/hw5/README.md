# Домашняя работа № 5 — Vue 3 и npm

Одностраничное приложение заметок «Т-Пульс Notes», созданное на Vue 3 с использованием Vite и пакетного менеджера npm.

## Запуск проекта

```bash
npm install
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

Команда `npm run build` создаёт оптимизированную сборку в каталоге `dist`.

## Использованные команды npm

```bash
npm create vite@latest . -- --template vue
npm install
npm run dev
npm run build
npm run preview
```

## Компоненты

- `App.vue` — корневой компонент и состояние приложения;
- `AppHeader.vue` — шапка и переключатель темы;
- `NoteForm.vue` — форма создания заметки с `v-model`;
- `NoteStats.vue` — вычисляемая статистика коллекции;
- `NoteToolbar.vue` — поиск и фильтрация заметок;
- `NoteList.vue` — список с `TransitionGroup`;
- `NoteCard.vue` — карточка, редактирование и пользовательские события.

## Возможности приложения

- добавление, редактирование и удаление заметок;
- завершение и закрепление заметок;
- поиск по заголовку, тексту и категории;
- фильтры по состоянию;
- автоматический пересчёт статистики через `computed`;
- обмен данными между компонентами через `props` и `emit`;
- сохранение заметок и темы в `localStorage`;
- светлая и тёмная темы;
- адаптивная вёрстка и доступные подписи элементов управления.

## Основные изученные возможности Vue

В проекте применены Single-File Components, Composition API, `<script setup>`, реактивные переменные `ref`, вычисляемые значения `computed`, наблюдатели `watch`, директивы `v-model`, `v-for`, `v-if`, динамические классы и пользовательские события компонентов.
