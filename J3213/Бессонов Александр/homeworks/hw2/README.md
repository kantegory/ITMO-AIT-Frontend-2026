# Домашняя работа №2 — доступность в HTML

В работе улучшена доступность сервиса управления проектами «T-Пульс», созданного на основе лабораторной работы №2.

## Запуск

```bash
npm ci
npm start
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Что реализовано

- семантические области страницы и правильная структура заголовков;
- ссылка быстрого перехода к основному содержимому;
- подписи полей форм, кнопок, таблиц и индикаторов прогресса;
- ARIA-состояния для переключателей, фильтров и динамического контента;
- скрытие декоративных иконок от программ чтения с экрана;
- заметный фокус клавиатуры и поддержка `prefers-reduced-motion`;
- открытие карточек доски клавишами `Enter` и `Space`;
- перемещение карточек между колонками сочетаниями `Ctrl + ←` и `Ctrl + →`;
- исправление контрастности текста и различимости ссылок.

## Результаты проверки

- Lighthouse Accessibility для страницы входа: **100/100**;
- Lighthouse Accessibility для страницы регистрации: **100/100**;
- синтаксис JavaScript проверен командой `node --check`;
- дополнительно рекомендуется проверить навигацию клавишей `Tab` и дерево доступности в Firefox Accessibility Inspector.
