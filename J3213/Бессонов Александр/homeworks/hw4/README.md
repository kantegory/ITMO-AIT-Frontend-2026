# Домашняя работа №4 — SVG-спрайт

В работе иконки сервиса управления проектами «T-Пульс» перенесены из внешнего иконочного шрифта Bootstrap Icons в единый локальный SVG-спрайт.

## Запуск

```bash
npm ci
npm start
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Что реализовано

- создан общий файл `assets/icons/sprite.svg`, содержащий 71 SVG-символ;
- статические иконки на всех страницах подключены через элементы `<svg>` и `<use>`;
- динамические иконки в `assets/js/app.js` и `assets/js/theme.js` также используют спрайт;
- удалена зависимость от CSS и шрифта Bootstrap Icons CDN;
- исходные контуры Bootstrap Icons 1.13.1 используются по лицензии MIT, полный текст которой сохранён рядом со спрайтом;
- иконки наследуют цвет через `currentColor` и корректно работают в светлой и тёмной темах;
- декоративные SVG скрыты от вспомогательных технологий, а интерактивные элементы сохраняют текстовые метки и `aria-label`;
- сохранены переключение темы, показ пароля, избранное, канбан-доска и остальные интерактивные сценарии предыдущих работ.

## Пример подключения

```html
<svg aria-hidden="true" class="icon" focusable="false">
  <use href="assets/icons/sprite.svg#icon-search"></use>
</svg>
```

Идентификатор каждого символа имеет формат `icon-название`. Размер и цвет задаются для класса `.icon` средствами CSS.

## Как проверить

1. Откройте основные страницы сайта и убедитесь, что все иконки отображаются.
2. Переключите светлую и тёмную темы — цвет иконок должен измениться вместе с интерфейсом.
3. Проверьте динамические иконки: показ пароля, избранное и переключатель темы.
4. В панели Network убедитесь, что загружается `assets/icons/sprite.svg`, а запросов к Bootstrap Icons нет.

Основные файлы работы: `assets/icons/sprite.svg`, `assets/css/styles.css`, `assets/js/app.js` и `assets/js/theme.js`.
