# Домашняя работа №3 — CSS-переменные и темизация

В работе выполнена темизация сервиса управления проектами «T-Пульс». Светлая и тёмная темы построены на общих семантических CSS-переменных.

## Запуск

```bash
npm ci
npm start
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Что реализовано

- две полноценные темы: светлая и тёмная;
- цветовые токены для текста, фонов, поверхностей, границ, состояний и теней;
- автоматический выбор темы через `prefers-color-scheme` при первом открытии;
- доступный переключатель темы на всех страницах;
- сохранение ручного выбора в `localStorage`;
- применение темы до загрузки основных стилей без заметного мерцания;
- отдельные значения Bootstrap-компонентов, форм, таблиц, модальных окон и канбан-доски;
- сохранение клавиатурной навигации и настроек `prefers-reduced-motion` из ДЗ2.

## Как проверить

1. Откройте любую страницу сайта.
2. Нажмите кнопку с иконкой луны или солнца в верхней панели.
3. Перейдите на другую страницу и убедитесь, что выбранная тема сохранилась.
4. Удалите ключ `t-pulse-theme` из `localStorage` и перезагрузите страницу — тема снова будет выбрана по системной настройке.

Основные файлы темизации: `assets/css/styles.css` и `assets/js/theme.js`.
