# TripPlanner

## Отчет о проделанной работе

### Тема лабораторной работы
Разработано многостраничное статическое веб-приложение для планирования путешествий и маршрутов.

### Цель работы
Создать полностью рабочий frontend-проект без backend и сборщиков, используя:

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- localStorage

Приложение должно работать как обычный статический сайт через переходы между `html`-файлами.

## Что реализовано

### 1. Главная страница `index.html`
- адаптивная landing-страница;
- единая navbar;
- hero-блок;
- блок преимуществ;
- блок популярных направлений;
- блок “Как это работает”;
- CTA-секция;
- footer.

### 2. Страница входа `login.html`
- форма входа;
- клиентская валидация email и пароля;
- уведомление об успешном входе;
- переход в личный кабинет;
- имитация авторизации через `localStorage`.

### 3. Страница регистрации `register.html`
- форма регистрации;
- валидация обязательных полей;
- проверка email;
- проверка пароля и подтверждения пароля;
- сохранение пользователя в `localStorage`;
- модальное окно об успешной регистрации.

### 4. Личный кабинет `dashboard.html`
- отображение данных пользователя;
- редактирование профиля через modal;
- статистика по маршрутам, заметкам и избранному;
- вкладки Bootstrap;
- добавление и удаление маршрутов;
- создание, редактирование и удаление заметок;
- отображение избранных направлений;
- выход из профиля.

### 5. Каталог направлений `destinations.html`
- вывод карточек направлений через JavaScript;
- фильтрация по:
  - названию;
  - типу;
  - бюджету;
  - длительности;
- сортировка;
- пагинация;
- сохранение направления в избранное.

### 6. Детальная страница направления `destination-details.html`
- загрузка данных по `id` из query string;
- отображение описания, рекомендаций, достопримечательностей;
- план поездки по дням;
- карта;
- отдельный погодный блок;
- отзывы пользователей;
- добавление отзыва;
- добавление направления в избранное;
- добавление направления в маршрут через modal;
- обработка случая, если `id` отсутствует или не найден.

### 7. Совместное планирование `collaboration.html`
- список участников поездки;
- приглашение участника через modal;
- общий маршрут с добавлением, редактированием и удалением этапов;
- общие заметки;
- идеи и рекомендации;
- поддержка идей голосами;
- хранение данных в `localStorage`;
- доступ к разделу только после входа в аккаунт.

## JavaScript-логика

### В `main.js`
Реализованы общие функции:

- работа с `localStorage`;
- добавление и удаление элементов из массивов;
- генерация `id`;
- безопасный вывод текста;
- показ Bootstrap toast;
- подсветка активного пункта navbar;
- показ и скрытие пунктов навигации в зависимости от авторизации.

### В остальных JS-файлах
- `auth.js` — логика входа и регистрации;
- `dashboard.js` — кабинет пользователя;
- `destinations.js` — фильтрация и каталог;
- `destination-details.js` — детальная страница;
- `collaboration.js` — совместное планирование;
- `data.js` — массив направлений и данные карточек.

## Хранение данных

Так как backend не используется, данные сохраняются на клиентской стороне:

- пользователь;
- текущая авторизация;
- маршруты;
- заметки;
- избранные направления;
- участники совместной поездки;
- этапы маршрута;
- общие заметки;
- идеи и голоса.

Все это хранится в `localStorage`.

- работает как статический сайт;
- содержит реальную интерактивность;
- использует Bootstrap и JavaScript по назначению;
- соответствует теме лабораторной работы;
- не является макетом или набором заглушек.

## Как запустить

1. Открыть папку проекта.
2. Запустить `index.html` в браузере.
3. Переходить по страницам через обычные ссылки сайта.

Для корректной проверки логики лучше использовать обычный современный браузер с включенным `localStorage`.
