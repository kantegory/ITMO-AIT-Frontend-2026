# Лабораторная работа №3 — Project Manager SPA

Миграция приложения из ЛР1 и ЛР2 на **Vue.js 3**. Приложение предназначено для управления проектами и командной работы.

## Что реализовано

- `vue-router`: главная страница, вход, регистрация, список проектов, страница проекта, 404.
- Navigation guards и `meta`: страницы проектов доступны только авторизованным пользователям; страницы входа/регистрации скрыты от уже авторизованного пользователя.
- Работа с внешним mock API через `axios`.
- Mock API реализован с помощью `json-server` в каталоге `server/` и файла `server/db.json`.
- Компонентный подход: отдельные компоненты шапки, футера, переключателя темы, фильтров, карточки проекта, формы создания, команды, файлов, комментариев и уведомлений.
- Composable-функции:
  - `useAuth` — авторизация, регистрация, сессия пользователя и выход;
  - `useTheme` — светлая/тёмная тема и сохранение выбора;
  - `useProjectFilters` — поиск и фильтрация списка проектов.
- Поиск проектов и фильтры по статусу, приоритету и исполнителю.
- Создание проекта.
- Вступление в проект.
- Страница проекта с составом команды, ролями, приглашением и удалением участников.
- Добавление/удаление файлов (метаданные в mock API).
- Комментарии к проекту.
- Светлая и тёмная темы.

## Структура

```text
src/
  api/             axios-клиент и модули API
  components/      переиспользуемые Vue-компоненты
  composables/     повторно используемая логика
  layouts/         общий layout приложения
  router/          маршруты и navigation guards
  views/           страницы 
  assets/          стили и темы
```

## Запуск

Требуется Node.js 22.18+.

Сначала установите зависимости клиента и API:

```bash
npm install
cd server
npm install
cd ..
```

Затем откройте два терминала. В первом:

```bash
npm run api
```

Во втором:

```bash
npm run dev
```

Адреса:

- Vue/Vite: http://localhost:8080
- JSON Server API: http://localhost:3001

Тестовый пользователь:

```text
Email: alexey@example.com
Пароль: 123456
```

## Соответствие требованиям ЛР3

1. **Роутер** — `src/router/index.js`.
2. **Внешний API через axios** — `src/api/http.js` и модули в `src/api/`.
3. **Компонентный подход** — каталог `src/components/`.
4. **Composable** — каталог `src/composables/` (`useAuth`, `useTheme`, `useProjectFilters`).
