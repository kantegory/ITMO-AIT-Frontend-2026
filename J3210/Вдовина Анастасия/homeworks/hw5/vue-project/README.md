# EventTix — учебное приложение на Vue

Домашняя работа 5: знакомство с npm и создание проекта на Vue.
Список мероприятий загружается с мокового API и пополняется через форму.

## Запуск

Установить зависимости:

```sh
npm install
```

Поднять сервер данных (json-server на порту 3000):

```sh
npm run api
```

В отдельном терминале запустить приложение (порт 8080):

```sh
npm start
```

## Структура

- `src/api` — экземпляр axios и класс для запросов к серверу
- `src/stores` — хранилище Pinia: состояние и действия
- `src/router` — маршруты
- `src/layouts` — общая обёртка страницы
- `src/views` — страница со списком мероприятий
- `src/components` — карточка мероприятия
