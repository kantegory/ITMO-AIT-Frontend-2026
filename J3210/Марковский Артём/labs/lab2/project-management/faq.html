Справка

Короткая справка по основным разделам и ролям.

Роль задаётся отдельно внутри каждого проекта. Поэтому в одном месте можно редактировать данные, а в другом только смотреть.

  • Администратор меняет состав команды и основные настройки проекта.
  • Участник работает с задачами и материалами проекта.
  • Наблюдатель может смотреть прогресс, но ничего не меняет.

В поиске можно отфильтровать задачи и перейти в нужный проект.

  • Поиск по названию задачи или проекта.
  • Фильтрация по статусу, приоритету и исполнителю.
  • Переход в проект прямо из результата поиска.

На странице проекта лежит всё основное, чтобы не прыгать по разным разделам.

  • Доска задач по статусам.
  • Сроки проекта по этапам.
  • Файлы проекта и обсуждения команды.
  • Блок с ролью и списком доступных действий.
