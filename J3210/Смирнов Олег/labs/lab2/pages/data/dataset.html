SQuAD v2.0

Stanford Question Answering Dataset — набор данных для задачи извлечения ответов из текста. Содержит более 100 000 пар вопрос-ответ на основе статей из Википедии. Версия 2.0 также включает вопросы без ответа.

Структура

  • Контекст — абзац из Википедии
  • Вопрос по содержимому абзаца
  • Ответ — фрагмент текста или пустой (нет ответа)

Пример загрузки

from datasets import load_dataset

dataset = load_dataset("squad_v2")
print(dataset["train"][0])
