meta/llama-3-70b

Автор: meta

генерация текста PyTorch Llama 3

Llama 3 70B

Открытая языковая модель от Meta для генерации текста, рассуждений и написания кода. Контекстное окно — 8K токенов.

Возможности

  • Генерация и суммаризация текста
  • Написание кода на популярных языках
  • Мультиязычная поддержка

Ограничения

  • Может генерировать некорректную информацию
  • Качество зависит от языка запроса

Пример использования

from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("meta-llama/Meta-Llama-3-70B")
model = AutoModelForCausalLM.from_pretrained("meta-llama/Meta-Llama-3-70B")

inputs = tokenizer("Привет, как дела?", return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=100)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
