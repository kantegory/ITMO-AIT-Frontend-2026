Задача

Улучшить доступность ранее реализованного сайта. Добавить необходимые HTML-атрибуты ко всему контенту на странице и проверить это с помощью инструментов из Dev Tools браузера Firefox и сервиса Google Lighthouse.

Ход работы

Работа по улучшению доступности была проведена на всех 7 страницах сайта MLOps Deploy. Ниже описаны внесённые изменения по категориям.

1. Ссылка для пропуска навигации (skip-nav)

На каждую из 7 страниц добавлена скрытая ссылка "Перейти к основному содержанию", которая становится видимой при фокусе клавиатурой (Tab). Это позволяет пользователям скринридеров и клавиатурной навигации быстро перейти к основному контенту, минуя навигационную панель.

<a class="visually-hidden-focusable" href="#main-content">
  Перейти к основному содержанию
</a>

Соответственно, тегу <main> на каждой странице добавлен id="main-content".

2. ARIA-метки на навигации

  • Всем тегам <nav> добавлен атрибут aria-label="Основная навигация".
  • Кнопке-гамбургеру добавлен aria-label="Открыть меню навигации".
  • На активных ссылках навигации добавлен aria-current="page" для обозначения текущей страницы.

3. Декоративные иконки

Все декоративные иконки Bootstrap Icons (<i class="bi bi-...">) помечены атрибутом aria-hidden="true", чтобы скринридеры их игнорировали. Всего помечено 15 иконок на разных страницах.

5. ARIA-метки на интерактивных элементах

  • Кнопка показа/скрытия пароля: aria-label="Показать пароль".
  • Все кнопки закрытия модальных окон: aria-label="Закрыть" (13 кнопок).
  • Панель фильтров: role="search" aria-label="Фильтры пайплайнов".
  • Поле поиска: aria-label="Поиск пайплайнов".

6. Динамический контент (aria-live)

Контейнеры, содержимое которых обновляется через JavaScript (загрузка из API), помечены атрибутом aria-live="polite":

  • Список пайплайнов на pipelines.html
  • Три вкладки профиля (пайплайны, артефакты, политики) на profile.html
  • Контейнер шагов на pipeline.html
  • Контейнер сред на environments.html

Сообщение "Пайплайны не найдены" помечено role="status".

7. Таблицы

Заголовкам таблицы ролей на environments.html добавлен атрибут scope="col" для правильного связывания заголовков с ячейками данных.

8. Стили доступности в CSS

  • Добавлены стили :focus-visible для кнопок и полей ввода с зелёным контуром (outline: 2px solid var(--accent)).
  • Добавлен медиа-запрос @media (prefers-reduced-motion: reduce), отключающий все анимации для пользователей с настройкой "уменьшить движение".
  • Стили для класса .visually-hidden-focusable для ссылки пропуска навигации.

Вывод

В ходе выполнения домашней работы доступность сайта MLOps Deploy была улучшена по нескольким направлениям: навигация с клавиатуры (skip-nav, focus-visible), поддержка скринридеров (aria-label, aria-hidden, aria-live, aria-current, role), семантика форм (autocomplete, label/for), таблицы (scope), и учёт пользовательских настроек (prefers-reduced-motion). Изменения затронули все 7 страниц сайта и файл стилей.
