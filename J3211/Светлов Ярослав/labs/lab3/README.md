# ЛР3 — ML-платформа на Vue

Vue 3, Vue Router, Axios, Bootstrap, Chart.js и отдельный JSON Server с авторизацией. Node.js 22.12+ (проверено на 22.22.2).

## Запуск

```sh
npm ci
npm run api
```

Во втором терминале из этой же папки: `npm start`.

- Приложение: http://localhost:8086.
- API: http://localhost:3006; Vite перенаправляет запросы `/api/*`.
- Аккаунты: `admin@nexus.ai` / `password`, `vision@nexus.ai` / `cv12345`.
- `npm test`: API-тесты с временной базой, пользовательские данные не меняются.
- `npm run build`: сборка в `dist`. Для проверки сборки вместо `npm start` запустить `npm run preview`; API оставить включённым.

При первом запуске `db.json` копируется в игнорируемый `db.local.json`. Новые пользователи и версии сохраняются в рабочей базе. Начальные примеры остаются неизменными. Артефакты — небольшие демонстрационные файлы, не настоящие веса моделей. Статус Production имитирует развёртывание.

## Структура

`src/views` — страницы; `src/components` — таблицы, навигация, график и артефакты; `src/composables` — сессия и состояния запросов; `src/api.js` — Axios; `src/router.js` — маршруты и проверка входа; `server.cjs` — API и проверка владельцев.

Учебный сервер привязан к localhost. `json-server-auth@2.1.0` использует устаревшую зависимость JWT, которую отмечает `npm audit`. Не использовать реальные пароли и не выставлять этот mock API в интернет.
