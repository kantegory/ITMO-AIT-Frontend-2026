# ЛР2 — платформа управления ML-экспериментами

Светлов Ярослав, J3211. Вариант 2.

HTML, Bootstrap и обычный JavaScript. Данные загружаются через `fetch` из
JSON Server 0.17.4, авторизация — json-server-auth 2.1.0.

## Запуск

Нужны Node.js 22 и npm. Выполнить из этой папки:

```bash
npm ci
npm start
```

Открыть http://localhost:3000. Сервер одновременно отдаёт API, страницы,
Bootstrap и Chart.js. После установки зависимостей интернет не нужен.
Открывать `public/index.html` напрямую через `file://` не следует.

Демонстрационные аккаунты:

| Email | Пароль |
| --- | --- |
| admin@nexus.ai | password |
| vision@nexus.ai | cv12345 |

При первом запуске `db.json` копируется в `db.local.json`. Новые пользователи,
версии и статусы сохраняются в локальной копии; исходные данные не изменяются.
Для сброса остановите сервер и переместите `db.local.json` в другую папку:
следующий запуск восстановит исходные данные.

## Возможности

- Регистрация, вход, восстановление сессии после обновления страницы и выход.
- Кабинет с собственными экспериментами, версиями моделей и артефактами.
- Поиск по дате, минимальной accuracy, максимальной latency и тексту; сброс фильтров.
- Детали выбранного эксперимента: график, таблица метрик, логи, скачивание файлов.
- Реестр моделей: новая версия связана со своим экспериментом; статус можно
  изменить на Staging, Production или Archived. Чужие модели доступны только для чтения.

Данные учебные. Production означает имитацию деплоя, реальная модель не запускается.
Артефакты — небольшие JSON с метриками и TXT с логами, их размеры указаны в байтах.
Новый пользователь получает пустой кабинет: создание экспериментов в этой работе не реализуется.

## API

| Метод | Адрес | Назначение |
| --- | --- | --- |
| POST | `/register`, `/login` | Регистрация и вход, ответ содержит `accessToken` и `user` |
| GET | `/users/:id` | Только свой профиль, без пароля |
| GET | `/experiments` | Каталог экспериментов после входа |
| GET | `/experiments/:id` | Метрики, логи и артефакты эксперимента |
| GET | `/models` | Все версии моделей после входа |
| POST | `/models` | Создание своей версии в статусе Staging |
| PATCH | `/models/:id` | Изменение поля `stage` своей версии |

Защищённые запросы используют заголовок `Authorization: Bearer <accessToken>`.
Фильтры: `date`, `accuracy_gte`, `latencyMs_lte`, `q`; `userId` — для кабинета.
Версия модели имеет формат `1.0.0`; повторное сочетание владельца, названия
и версии отклоняется. Неизвестные записи возвращают 404, недостаток прав — 403,
недействительный токен — 401. Сессия хранится под ключом `nexus_lab2_session`.

## Проверка

```bash
npm test
```

Девять API-тестов запускают сервер на свободном порту с временной копией базы:
проверяют вход и регистрацию, доступ к профилю, фильтры, детали и файлы,
создание версий, сохранение статуса и запрет изменения чужих моделей.
Они не меняют `db.json` или `db.local.json`.

Интерфейс проверен в Chromium и Firefox 148: формы, поиск, график,
создание версии, смена статуса, обновление страницы и выход.
Дополнительно проверены пустой кабинет, повторный email, неверный пароль,
недействительная сессия, неизвестный эксперимент и остановленный API.
Узкие экраны: Chromium 360 px, Firefox 500 px. Широкие таблицы прокручиваются
внутри своего блока.
