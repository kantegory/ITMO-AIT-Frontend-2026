# ЛР1 — статический прототип

Исходные `index.html`, `script.js`, `style.css` скопированы без изменений из `pr-198` (совпадают с веткой `lab1`).

Из этой папки запустить:

```sh
python3 -m http.server 3001 --bind 127.0.0.1
```

Открыть http://localhost:3001. Для Bootstrap, Chart.js и иконок из CDN требуется интернет. Вход имитируется; настоящей проверки пароля нет.

В ходе браузерной проверки найдены ошибки выбора эксперимента и мобильной вёрстки. Управление, деплой и скачивание файлов остаются заглушками. Подробности и скриншоты — в [отчёте](Отчёт.pdf), исходник — [LaTeX](report.tex). Код при подготовке отчёта не исправлялся.
