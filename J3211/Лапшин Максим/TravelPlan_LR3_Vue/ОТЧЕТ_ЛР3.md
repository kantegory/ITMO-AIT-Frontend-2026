# Отчёт по лабораторной работе №3

## Цель работы

Освоить разработку одностраничного веб-приложения с использованием Vue.js, научиться организовывать интерфейс через компоненты, подключать маршрутизацию и получать данные из внешнего REST API.

## Постановка задачи

Требовалось мигрировать ранее созданное приложение TravelPlan на Vue.js. Приложение должно использовать роутер, axios для взаимодействия с API, компонентный подход и composable для выделения повторяющейся логики.

## Ход выполнения работы

За основу был взят сервис TravelPlan из предыдущих лабораторных работ. В исходной версии каждая страница представляла собой отдельный HTML-файл, а поведение реализовывалось одним JavaScript-файлом. В новой версии приложение стало SPA: браузер один раз загружает `index.html`, а смена страниц выполняется Vue Router без полной перезагрузки.

Для страниц созданы представления `HomeView`, `TourDetailsView`, `DashboardView`, `LoginView`, `RegisterView` и `NotFoundView`. Для повторяющихся элементов выделены компоненты бокового меню, переключателя темы, фильтра, карточки тура и индикатора загрузки.

Работа с данными выполняется через REST API на базе JSON Server. В `src/services/api.js` создан экземпляр axios с базовым адресом API. Главная страница получает список туров и параметры фильтров запросами `GET`. Страница отдельного тура получает объект по его идентификатору. При регистрации отправляется запрос `POST /users`.

Повторяющаяся логика вынесена в composable. `useTours` отвечает за получение и фильтрацию туров, `useTheme` — за светлую и тёмную темы, `useAuth` — за состояние пользователя, `useFavorites` — за избранные путешествия, `useTravelNotes` — за заметки в личном кабинете.

## Результат

Получено Vue SPA-приложение TravelPlan, которое позволяет просматривать и фильтровать туры, открывать подробную карточку, регистрироваться, входить в личный кабинет, сохранять избранные маршруты и заметки, а также переключать тему оформления.

## Вывод

В ходе лабораторной работы было выполнено преобразование многостраничного приложения в SPA на Vue.js. Были применены Vue Router, axios, компоненты и Composition API/composable. Архитектура стала более структурированной: представления отвечают за страницы, компоненты — за интерфейс, сервис — за API, а composable — за повторяемую бизнес-логику и состояние.
